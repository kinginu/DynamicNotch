# Changelog

All notable changes to the DynamicNotch app are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/). Detailed engineering notes (in Japanese) are in
[BUILD-LOG.md](BUILD-LOG.md).

## [1.0.0] — 2026-10-21

First release (`CFBundleShortVersionString` 1.0.0, `CFBundleVersion` 1). Built locally and ad-hoc
signed; no binaries are distributed.

### Platform

- **macOS 26** or later, **Apple Silicon** MacBooks with a notch. Built with Xcode 26.6 from an
  XcodeGen spec (`project.yml`). English UI only.
- Bundles **FanControl 1.0.0** (helper XPC protocol version 2). The privileged helper is installed
  by hand with `FanControl/Support/manual-install/install.sh` (re-run after every rebuild, because
  the helper pins the app's cdhash).
- The only external package is `mediaremote-adapter`. Sparkle, SmoothGradient, Lottie,
  RichTextKit, CodeEditor/Highlightr and Defaults were replaced with first-party APIs.
- No assets from third-party apps are bundled: the app icon is generated by
  `Support/make-app-icon.swift`, and the only resources are the icon, `en.lproj/Localizable.strings`
  and the MediaRemoteAdapter bundle.

### Notch

- One notch window per screen; it opens on hover only on the screen under the pointer, waits
  before closing, and stays open while a menu, popover, sheet or text field is in use.
- Width and height follow the widgets that are shown; background and content share one animatable
  notch shape and one spring per direction.
- Closed-notch **Live Activities**: media, battery, calendar, timer (iOS Dynamic Island style, with
  ring countdown), downloads progress, tray, fan warnings and the volume / brightness /
  keyboard-backlight **HUD**.
- **Tray** with file drop into the notch and an AirDrop drop target.

### Widgets

Calendar, Media, Shortcuts, Camera (aspect-correct preview), Notes, Quick Apps, Timer (configurable
presets), **Fan Control**, **Temperature**, Clipboard history, Hidden menu bar items, Reminders
(EventKit), Storage, System (CPU / GPU / memory / disk), Next Up, Batteries (Mac, Magic accessories,
AirPods, BLE devices), Calculator, Bluetooth, Focus (Pomodoro), Weather (Open-Meteo), Network,
Audio devices (with AirPods listening-mode switch), World Clock, Keep Awake, Color Picker, Capture,
Downloads, Usage (self-collected, off by default) and Displays (built-in brightness and DDC/CI for
external monitors). Widgets are arranged in **pages** (two-finger swipe, ←/→, drag to reorder and
move between pages).

### Fan control

- Profiles: Automatic (SMC), Quiet 3000 RPM, High 5000 RPM, Max 6800 RPM, Boost (sensor-linked to
  `agg:cpu`, 50 → 85 °C) and two Custom slots with a multi-point curve editor; picking a profile in the notch
  applies it at once.
- Power profiles (power source, lid, time of day) and app / sustained-load linked profiles, with
  one arbiter deciding precedence; optional Low Power Mode switching and charge limit (where the
  Mac supports `CHWA`).
- Sleep/wake safety, drift repair, emergency override and other-fan-app warnings come from the
  FanControl package.

### Automation

- `dynamicnotch://` URL scheme, App Intents / App Shortcuts and the `dnctl` command-line tool
  ([docs/automation.md](docs/automation.md)). Screenshots from URLs need the opt-in setting
  "Allow automation to take screenshots" (off by default).

### Settings

- SwiftUI `Settings` scene with fixed 760×640 panes, an About pane, and settings stored through
  `SettingsStore` / `@StoredSetting`.

### Known limitations

- Visual checks of several widgets are still pending on hardware; see `BUILD-LOG.md`.
- The notch window is an `NSWindow`, so clicking it can activate the app.
- `mediaremote-adapter` relies on the private `MediaRemote.framework`.
